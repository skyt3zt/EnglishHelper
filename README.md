# WordCatcher 单词捕手

WordCatcher 是一款轻量、强大的 Chrome / Edge 浏览器扩展插件。它旨在帮助用户在沉浸式英文阅读的同时，无缝捕获生词，并结合艾宾浩斯遗忘曲线（Spaced Repetition）智能安排复习，让单词记忆更加高效。

## ✨ 核心功能 (Features)

*   **划词翻译与捕获**：在任意网页选中文本，即可呼出翻译气泡，一键查看释义、音标并将其加入生词本，同时自动截取生词所在的上下文例句。
*   **多语言翻译支持**：支持将外语翻译为中文（简体/繁体）、日语、韩语、西班牙语、法语、德语、俄语等多国语言。
*   **智能复习提醒 (Spaced Repetition)**：内置基于艾宾浩斯遗忘曲线的复习算法。每天自动计算并提示需要复习的单词数量。
*   **全功能控制台 (Dashboard)**：
    *   **单词管理**：查看所有已收集的单词及其详细释义、音标和上下文。
    *   **实时搜索**：支持中英文双搜，秒级过滤定位你需要的单词。
    *   **拖拽排序**：支持通过拖拽左侧的 `⋮⋮` 句柄，随心所欲地调整生词列表中单词的顺序。
    *   **单词置顶**：支持最多将 3 个核心词汇高亮并置顶（📌），随时在页面最醒目的位置强化记忆。
    *   **状态切换**：可将单词标记为“已掌握”或直接删除。
    *   **隐藏导入**：双击页面左上角标题即可触发隐藏彩蛋，通过 CSV 文件一键恢复词库数据，全程智能防重复。
*   **优雅的弹出窗口 (Popup)**：
    *   随时点击浏览器右上角的插件图标，即可查看今日需要复习的词数，以及最新捕获的生词。
    *   自适应宽度的弹窗排版，拒绝拥挤，提供极致的阅读体验。
*   **数据导出**：支持一键将生词本全量导出为 `.csv` 格式，方便导入 Anki 等第三方记忆软件（高级版专属）。

## 🚀 安装指南 (Installation)

由于目前插件为本地开发者版本，尚未上架浏览器插件商店，请按照以下步骤加载使用：

1. 下载并解压本项目源码到本地电脑。
2. 打开你的 Chromium 内核浏览器（如 Google Chrome 或 Microsoft Edge）。
3. 在地址栏输入 `chrome://extensions/`（或 `edge://extensions/`）并按下回车。
4. 在页面右上角（或左下角）打开 **开发者模式 (Developer mode)** 开关。
5. 点击页面左上角的 **加载已解压的扩展程序 (Load unpacked)**。
6. 在弹出的文件夹选择窗口中，选中本项目中的 `extension` 文件夹并确认。
7. 成功！你现在可以在浏览器工具栏中看到 WordCatcher 的图标了。

## 💡 使用说明 (Usage)

1. **查词**：在浏览英文网页时，用鼠标划选任何一个你不认识的单词，页面上会浮现出翻译按钮。
2. **记录**：在弹出的浮窗中点击 ➕，即可将该单词及上下文例句收录至生词本，添加成功后图标会变为 ✅ 并直接为您浮现简略释义，无需跳转。
3. **查阅**：点击浏览器右上角的 WordCatcher 插件图标，可以快速浏览最近查阅的单词、修改目标翻译语言、或直达复习面板。
4. **管理**：在 Dashboard 控制台中，你可以长按单词左侧的把手进行上下拖拽排序，也可以点击“置顶”将重点单词固定在列表最前方。
